2. **[基礎設施][工程知識] Dogfooding at scale: migrating cdnjs to Cloudflare's Developer Platform**
   cdnjs 是每天服務約 90 億次請求、幾乎所有前端專案都依賴過的公共函式庫 CDN。這篇文章記錄 Cloudflare 團隊如何把 cdnjs 完全遷移到自家由 Workers、Workflows、R2、KV、Queues、Containers、Durable Objects 組成的 Developer Platform 上，過程中因為 cdnjs 這種極端規模的流量不斷「踩到」平台既有限制（例如每次 Worker 呼叫 1,000 次 subrequest、每個 Workflow 1,024 個 step 的上限），進而推動平台把付費方案的 subrequest 上限一路提高到 1,000 萬次。遷移後也讓需要維護資安的元件大幅減少——舊架構要顧 Cloud Functions、git-sync VM、容器映像、GCS bucket 與 service-account 金鑰，退役舊 pipeline 後等於一次關掉所有最近開出的 cdnjs 資安漏洞。是一篇「自己吃自己的狗糧」式的大規模基礎設施遷移實錄，對任何依賴 cdnjs 交付函式庫的前端專案都有參考價值。
   來源：The Cloudflare Blog（開放搜尋補充）｜https://blog.cloudflare.com/cdnjs-dev-platform-migration/
   發布日期：2026-07-30（近期，約 5 天前）

## 知名前端工程師個人部落格（1）

4. **[Blog][AI輔助開發] Addy Osmani — Own the Outer Loop**
   這是 Addy Osmani 在 AI Engineer World's Fair 2026 閉幕主題演講的文字化版本，提出一套給「agentic coding」時代的當責框架：AI agent 現在已經能自主跑完「內迴圈」（inner loop）——調查問題、寫程式碼、跑測試、回報結果；但工程師必須守住「外迴圈」（outer loop）——判斷這件事值不值得做、驗證 agent 產出的證據（diff、測試紀錄、log），並下 ship/block/redirect 的裁決、承擔最終後果。文中引用調查數據：96% 的工程師並不完全信任 AI 產出的程式碼，但只有 48% 真的會去驗證，並點名「用摘要取代審查」（summary substitution）是常見反模式。他把整套框架濃縮成三支柱：Quality（產生證據的檢查）、Verdict（裁決）、Answerability（能否解釋為什麼這樣裁決），延續他一貫「具體可照做」而非只講原則的寫作風格。
   來源：Addy Osmani 個人部落格（AGENTS.md 指定名單內的工程師，開放搜尋補充）｜https://addyosmani.com/blog/own-the-outer-loop/

5. **[GitHub Trending][框架][Rust] tokio-rs/topcoat**
   Topcoat 是由 Tokio 團隊主導開發（Carl Lerche、Julien Scholz）的全新 Rust 全端網頁框架，主打「不用 WebAssembly」也能做到伺服器渲染搭配前端即時互動——透過巨集把一部分 Rust 表達式編譯成 JavaScript，在瀏覽器端執行。內建依專案結構自動推斷的路由、資源打包管線，以及仿 shadcn/ui 風格、以 Tailwind 為基礎的元件庫，並可與 Axum、HTMX、Alpine.js 整合。範例（首頁與可切換內容的按鈕元件）：
   ```rust

       view! { <h1>"Hello"</h1> }
   }

   view! {
     signal open = false;
     <button @click=$(|_e| open.set(!open.get()))>"Toggle"</button>
     <p :hidden=$(!open.get())>"Content"</p>
   }
   ```
   對前端工程師而言，這代表 Rust 生態系首次出現可與 Next.js 抗衡的全端框架選項，約 4,200 star，近 7 天新增 931 star，值得關注後續發展。

7. **[React][型別安全] This Week In React #292**
   本期最大重點是 `stableref/react`——一個把「已被 memo 化」這件事直接搬進型別系統的函式庫：用 `Stable<T>` 標記記憶化後的值，只要 props 或 dependency array 沒被正確記憶化就會在編譯期報錯。範例：
   ```ts
   function Component(props: { onClick: Stable<() => void> }) {}
   // 呼叫端若傳入未經 useCallback 包裹的函式,型別檢查直接不過
   ```
   對持續追蹤 React 生態「怎麼用型別系統防呆」這個方向的工程師是很密集的一期。
   來源：This Week In React（優先來源）｜https://thisweekinreact.com/newsletter/292
   發布日期：2026-07-29（近期，約 6 天前）
